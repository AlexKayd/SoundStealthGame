
### Учебный проект по программированию игр на Unity (6000.3.14f1)
## Выполнила: Кайдалова Александра М8О-412Б-22
## Игрок-выживший должен пересечь карту, не привлекая внимания зомби, и добраться до бункера. Зомби лишены зрения и реагируют только на звук шагов.  

# Описание: 
- 1) Механика генерации звуковых волн с динамическим питчем. Движение игрока создаёт видимые звуковые импульсы, расширяющиеся от персонажа. Характеристики волн зависят от:
  - Скорости передвижения: ходьба создаёт тихие волны малого радиуса, бег - громкие волны большого радиуса.
  - Типа поверхности: покрытие землей генерирует низкочастотные волны (питч 0.7), деревянный пол - стандартный звук (pitch 1.0), металлические платформы - высокочастотный звонкий звук (питч 1.3)
- 2) Слуховой ИИ противников. Враги не имеют зрения, но реагируют на попадание волны в триггер слуха. При обнаружении звука враг использует NavMesh для движения к координатам источника. При сближении с игроком на критическое расстояние фиксируется поимка (рестарт сцены)."
  
# Геймплей и механики
- **Генерация звуковых волн**  
  При движении игрока создаются видимые импульсы (жёлтые кольца). Радиус зависит от скорости ходьба/бег, цвет постоянный.
- **Динамический питч звука**  
  Характеристики шагов меняются от типа поверхности:  
  - Земля – низкий, глухой (pitch 0.7)  
  - Дерево – обычный (pitch 1.0)  
  - Металл – высокий, звонкий (pitch 1.3)
- **Слуховой ИИ врагов**  
  Зомби не имеют зрения. Если звуковая волна попадает в триггер-слух, враг использует NavMesh для движения к источнику шума.  
  При сближении на критическое расстояние игрок попадается – сцена перезапускается.
- **Процедурная генерация**  
  Карта 12×12 плиток случайно заполняется тремя типами поверхностей. Враги также расставляются случайно, их плотность растёт к финишу.
- **Победное условие**  
  В конце карты расположен бункер. Зайдя в него, игрок побеждает, и сцена перезапускается через несколько секунд.

## Технологии Unity
- Universal Render Pipeline
- Shader Graph (универсальный шейдер пола с переключением текстур)
- Cinemachine (камера, плавно следующая за игроком)
- NavMesh + NavMeshSurface (навигация врагов)
- Line Renderer (визуализация звуковых колец)
- CharacterController, Animator, AudioSource
